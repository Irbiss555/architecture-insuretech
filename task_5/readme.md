## Как схема покрывает REST-операции


| REST эндпоинт                   | Эквивалент в GraphQL                             | Преимущество                                                                                             |
| ------------------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------------------------------- |
| **GET /clients/{id}**           | `query { client(id: "42") { id name age ... } }` | Выбираем **только нужные поля** (нет перетранспорта 500-полей объекта).                                  |
| **GET /clients/{id}/documents** | `client { documents { id type number } }`        | Запрашиваем документы сразу внутри того же вызова; кэш GraphQL-gateway соберёт данные в один round-trip. |
| **GET /clients/{id}/relatives** | `client { relatives { name relationType } }`     | То же: один запрос, и выбираются только нужные атрибуты.                                                 |

Дополнительный query `clients(ids: [...])` позволяет за один запрос получить данные сразу по нескольким

Схема GraphQL в файле `client-info.graphql`
